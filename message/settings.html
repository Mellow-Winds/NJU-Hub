帮助

请勿使用学校 edu.cn 邮箱注册 Resend 或收信，邮件可能被拒收或退回。建议使用自己的 QQ 邮箱或其他个人邮箱。

  1. 注册 Resend，在 API Keys 创建有发送权限的密钥。
  2. 填写该账号的注册邮箱，保存并发送测试邮件。
  3. 选中网页文字，右键选择“加入 NJU-Hub 消息订阅”。

共享测试发件地址无需验证域名，仅可发送到自己的 Resend 注册邮箱。插件无法提前核验邮箱归属，发送时由 Resend 校验。

API Key 不经 NJU-Hub 中转；确认发送后，主题、正文、本人邮箱及预约时间会直接交给 Resend 处理。本地存储不是加密保险箱，请使用专用发送密钥。

来源链接默认不附上；开启后，邮件含“点击跳转来源”。发送前请检查链接是否包含私人参数。

支持未来 30 天内预约，提交成功后由 Resend 执行。可在 Resend 控制台 核实投递、调整或取消预约。额度以控制台为准。
